# Управление таблицами

## Запуск

После установки пакета код можно запустить командой:

```bash
database
```

## Доступные команды

1. create_table -> создать таблицу
2. drop_table -> Удалить таблицу
3. list_tables - Показать список таблицу
4. help -> Показать справочную информацию
5. exit -> Завершить программу

## Примеры использования

Создание таблицы

```bash
Введите команду: create_table users name:str age:int is_active:bool
Таблица 'users' успешно создана.
```

Просмотр списка таблиц

```bash
Введите команду: list_tables
Список таблиц:
- users
```

Удаление таблицы

```bash
Введите команду: drop_table users
Таблица 'users' успешно удалена.
```

Завершение работы

```bash
Введите команду: exit
Выход из программы.
```

## CRUD. Доступные команды

1. insert into <таблица> values (<значения>) -> Добавление записи
2. select from <таблица> -> Получение всех записей
3. select from <таблица> where <условие> -> Получение записей по условию
4. update <таблица> set <изменение> where <условие> -> Изменение записей
5. delete from <таблица> where <условие> -> Удаление записей
6. info <таблица> -> Информация о таблице
7. help -> Справочная информация
8. exit -> Завершение работы

## Примеры использования

Запуск программы:

```bash
database
```

Создание таблицы:

```bash
create_table users name:str age:int is_active:bool
```

Добавление записи:

```bash
insert into users values ("Sergei", 28, true)
```

Получение всех записей:

```bash
select from users
```

Поиск по условию:

```bash
select from users where age = 28
```

Обновление записи:

```bash
update users set age = 29 where name = "Sergei"
```

Удаление записи:

```bash
delete from users where ID = 1
```

Вывод информации о таблице:

```bash
info users
```

## Описание декораторов

Декораторы находятся в `src/primitive_db/decorators.py`.

### Обработка ошибок — `@handle_db_errors`

Функции базы данных автоматически перехватывают `FileNotFoundError`, `KeyError`, `ValueError` и другие исключения и выводят понятные сообщения.

Пример:

```text
Ошибка валидации: Некорректное имя таблицы.
```

### Подтверждение действий — `@confirm_action(action_name)`

Декоратор используется в `drop_table` и `delete`. Перед удалением выводится запрос:

```text
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: n
Операция отменена.
```

Ответ `y` подтверждает выполнение, другие ответы отменяют операцию.

```python
result = delete(table_data, {"ID": 2})
if result is not None:
    table_data = result
```

### Замер времени — `@log_time`

Используется для `insert` и `select` и выводит длительность работы через `time.monotonic()`:

```text
Функция select выполнилась за 0.000 секунд.
```

### Кэширование через замыкание — `create_cacher()`

Функция создаёт замыкание со словарём кэша. `select` сохраняет индексы подходящих записей. При повторном запросе к тем же данным и с тем же условием фильтрация не выполняется повторно. Изменение содержимого таблицы меняет ключ и приводит к пересчёту результата.
